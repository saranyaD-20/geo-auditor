# 🌐 GEO Auditor

## Project Description

GEO Auditor is a web application that evaluates a website's readiness for AI-powered search engines like ChatGPT, Google AI Overviews, Claude, and Perplexity.

## Features

- Website URL Analysis
- Robots.txt Check
- Sitemap Check
- Meta Title & Description Analysis
- Schema.org Detection
- AI Readability Analysis
- GEO Score Calculation
- Recommendations
- Priority Fixes

## Tech Stack

Frontend
- React
- Axios

Backend
- Python
- Flask
- BeautifulSoup
- Requests

## Installation

### Backend

cd backend

python -m venv venv

pip install -r requirements.txt

python app.py

### Frontend

cd frontend

npm install

npm run dev
